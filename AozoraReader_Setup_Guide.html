Aozora Reader - Pygame 版 セットアップガイド

Pyxel 版テキストリーダーを Pygame に移植したプロジェクトの構成と実行方法

1. ディレクトリ構成

プロジェクトフォルダ（例: aozora-reader）には以下のファイルを配置します。

aozora-reader/ ├── main.py # エントリーポイント ├── reader.py # App クラス（メインアプリケーション） ├── input_manager.py # InputManager（btn/btnp 互換） ├── sound_manager.py # SoundManager（効果音管理） ├── palette.py # Pyxel 16色パレット定義 ├── requirements.txt # Python 依存パッケージ │ ├── PixelMplus10-Regular.ttf # フォント（10px用） ├── PixelMplus12-Regular.ttf # フォント（12px用） │ ├── aozora_416.txt # 表示するテキスト（青空文庫など） │ ├── beep_talk.wav # 通常タイピング音 ├── beep_space.wav # スペースキー高速時の音 ├── beep_fast.wav # 速タイピング音 └── beep_faster.wav # 超高速タイピング音

2. ファイルの役割

ファイル役割
main.pyエントリーポイント。App インスタンスを生成して run() を呼ぶ
reader.pyApp クラス。画面描画、タイピングアニメーション、ページ管理
input_manager.pyPyxel の btn/btnp に相当する入力管理。キーボード・マウス・ゲームパッド対応
sound_manager.pyWAV/OGG ファイルから効果音を読み込み再。ファイルがない場合は無音で動作
palette.pyPyxel デフォルト16色パレット（PICO-8）の RGB 定義
requirements.txtpip インストール用。pygame のみ記載

3. 実行までの手順

Step 1: リポジトリをクローン（または手動でファイルを配置）

# GitHub からクローンする場合
git clone https://github.com/YOUR_USERNAME/aozora-reader.git
cd aozora-reader

Step 2: 依存パッケージをインストール

pip install -r requirements.txt
注意: Linux の場合、pygame ビルドに SDL2 開発ライブラリが必要です。 
sudo apt-get install libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev libsdl2-ttf-dev

Step 3: アセットファイルを配置

以下のファイルをプロジェクトフォルダに配置してください。

  • PixelMplus10-Regular.ttf / PixelMplus12-Regular.ttf（フォント）
  • aozora_416.txt（テキストファイル）
  • beep_*.wav（効果音、任意）

フォントがない場合は OS の日本語フォントに自動フォールバックします。

Step 4: 実行

python3 main.py

操作方法

キー動作
RETURN / ↓ / マウス左クリック次へ進む / ページ送り
↑前のページに戻る
SPACE（長押し）高速タイピング
↓ + Zさらに高速
↓ + X超高速
Fフォントサイズ切り替え（10px / 12px）
R最初から再読み込み
Q / ESC終了

4. GitHub リポジトリの作成方法

方法A: コマンドラインから作成

# 1. ローカルで Git リポジトリを初期化
cd aozora-reader
git init

# 2. すべてのファイルをステージング
git add .

# 3. コミット
git commit -m "Initial commit: Aozora Reader Pygame version"

# 4. GitHub 上で空のリポジトリを作成
#    https://github.com/new から "aozora-reader" を作成

# 5. リモートを追加してプッシュ
git remote add origin https://github.com/YOUR_USERNAME/aozora-reader.git
git branch -M main
git push -u origin main

方法B: GitHub CLI を使う

# gh がインストール済みの場合
cd aozora-reader
git init
git add .
git commit -m "Initial commit"
gh repo create aozora-reader --public --source=. --push

方法C: GitHub ウェブからアップロード

  1. https://github.com/new を開く
  2. Repository name に aozora-reader を入力
  3. Public / Private を選択して「Create repository」
  4. 「uploading an existing file」をクリック
  5. プロジェクト内の全ファイルをドラッグ＆ドロップしてコミット

5. トラブルシューティング

pygame のインストールに失敗する

SDL2 開発ライブラリが不足しています。OS に応じてインストールしてください。

# Ubuntu / Debian
sudo apt-get install libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev libsdl2-ttf-dev

# Fedora
sudo dnf install SDL2-devel SDL2_image-devel SDL2_mixer-devel SDL2_ttf-devel

# macOS
brew install sdl2 sdl2_image sdl2_mixer sdl2_ttf

日本語が文字化けする / 豆腐になる

PixelMplus フォントが見つからない場合、OS のフォントにフォールバックします。 日本語対応フォントがインストールされているか確認してください。

# Linux の場合
sudo apt-get install fonts-noto-cjk

効果音が鳴らない

beep_*.wav ファイルが存在しないか、pygame.mixer の初期化に失敗しています。 ファイルを配置するか、無音で動作するため無視して問題ありません。

「ファイルが見つかりません」と表示される

aozora_416.txt がプロジェクトフォルダに配置されているか確認してください。

6. 次のステップ

Pygame 版が動作確認できたら、以下のステップに進めます。

  1. pygbag で Web 化: pip install pygbag してブラウザで動作させる
  2. GitHub Pages にデプロイ: pygbag ビルド結果を GitHub Pages で公開
  3. OGG 変換: WAV を OGG に変換してファイルサイズを削減
参考: pygbag 版のビルド手順は別途 PYGBAG_BUILD_README.md を参照してください
